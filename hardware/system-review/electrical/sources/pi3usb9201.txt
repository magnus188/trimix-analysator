1) Write 01h bit3 form 0 to 1 for Client mode detect after 00h bit 3-1 = 100 Client mode. For USB-C application, write 1 to 01h bit3 when the system in
ATTACHED.SNK state. Write 0 to 01h bit3 when it leaves ATTACHED.SNK state. For non-USB-C application, write 1 to 01h bit3 when the system detects the
existence of VBUS. Write 0 to 01h bit3 when VBUS is removed.
