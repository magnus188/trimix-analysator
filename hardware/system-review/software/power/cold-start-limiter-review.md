# Cold-start USB current limitation

**Historical candidate review.** The current native design selects U114 **TPS22950CQDDCRQ1**, the automotive DDC package, rather than the industrial TPS22950YBHR discussed below. Its documented low-current range differs from the industrial C/L variants. The current R119 is **19.1 kΩ**, so the manufacturer's **19.2 kΩ** test-point bounds below must not be presented as guaranteed bounds for the fitted resistor. See the [current interface contract](../../electrical/interface-contract.md), [part qualification ledger](../../electrical/part-qualification.csv) and [cold-recovery limitation](off-charge-review/standby-implementation.md). The original comparison is retained to explain the design history.

The BQ25895 cannot use its ILIM resistor to guarantee a 100 mA cold-start ceiling. TI's Rev C pin table explicitly excludes settings below 500 mA; its KILIM limits are characterized at 1.5 A. Therefore the earlier 4.02 kΩ / 98 mA inference is withdrawn. The supported alternative under implementation is an upstream current-limited switch, with the BQ retaining a fixed 300 Ω ILIM resistor. [TI BQ25895, pages 4, 9 and 26](https://www.ti.com/lit/ds/symlink/bq25895.pdf)

The preferred candidate is **TPS22950YBHR**, the ordinary auto-retry version. At the manufacturer's 19.2 kΩ test point its output-current limit is 34/50/66 mA, with up to 60 µA no-load supply current. A permanent resistor provides the cold setting; the existing two-series-MOSFET permission condition can add a parallel 1.0 kΩ resistor for the qualified setting. Input decoupling starts at 1 µF. ON must not float. The ball map is A1 ON, A2 FLT, B1 VIN, B2 VOUT, C1 GND, C2 ILIM. This is a 1.106 × 0.706 mm six-ball WCSP, requiring factory assembly acceptance; C/L variants do not support this low setting. [TI datasheet Rev B](https://www.ti.com/lit/ds/symlink/tps22950.pdf), [exact orderable part](https://www.ti.com/product/TPS22950/part-details/TPS22950YBHR)

The typical equation predicts about 1.246 A for 19.2 kΩ in parallel with 1.0 kΩ. This is a nominal estimate, not a guaranteed corner. A 300 Ω ±1% BQ resistor gives 390/297 = 1.313 A using the published KILIM maximum, contingent on its supported operation and EN_ILIM remaining enabled. The final upper-current assessment must include both regulators and their operating conditions. Resistor tolerance, switch leakage, source wiring and actual loop behaviour remain part of the electrical and physical qualification.

TPS22950's 5 µs current-limit response is typical, with no maximum listed. Finite response permits transient overshoot. The datasheet does not specify safe behaviour for an open or shorted ILIM programming resistor. FLT indicates thermal/reverse conditions and must not be interpreted as a general current-limit indication. This architecture provides a designed cold setting, not proof of every possible component fault or instantaneous USB compliance.

The alternatives were less suitable. TPS2553 has a specified 50/75/100 mA mode when ILIM is shorted to IN, but its quiescent current and other upstream loads leave no strict 100 mA margin; changing to its high-current resistor would also require appropriate analog selection. TPS22946 deliberately permits a larger startup current and therefore does not provide the requested simple low-current cold limit. [TI TPS2553](https://www.ti.com/lit/ds/symlink/tps2553.pdf), [TI TPS22946](https://www.ti.com/lit/ds/symlink/tps22946.pdf)

The low-current path cannot run the ESP32-P4 display by itself. Recovery of a deeply depleted pack requires a separately qualified off-device charging/precharge sequence. Commissioning firmware still inhibits charging; no pack-recovery test is claimed. Bench tests must cover capacitor inrush, limiting-loop interaction, 5 V source droop, full/empty/disconnected batteries, protection-holder recovery, thermal behaviour and source changes while the host is stalled. The source supervisor remains on raw USB_5V so downstream current limiting does not itself impersonate a cable detach.
