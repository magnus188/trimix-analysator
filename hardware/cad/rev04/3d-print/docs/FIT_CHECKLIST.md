Use an unpowered assembly for the first fit. Record actual values rather than a
pass alone. Leave untested items pending. Photograph interference before
changing a printed part, and identify it using its TMX-A3 part ID.

Use the PLA project for dimensional fit and the PETG project for the target
material trial. Select the actual insert SKU and qualify its coupon before
heat installation in full parts. Current M2 holes around 3.2/3.3 mm and M3
holes around 4.3 mm are clearance references. Record the qualified hole size
and update the part before installing the inserts.
