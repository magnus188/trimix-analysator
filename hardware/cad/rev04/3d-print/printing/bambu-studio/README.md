# Bambu Studio projects

These are the prepared A3 `.3mf` projects. Choose `pla/` for unpowered fit
prototypes or `petg/` for the next material trial, then open the file inside the
matching part directory in Bambu Studio.

Each part directory also contains its slice output and inspection images. Check
the real spool, build plate, nozzle and support preview before printing. These
projects have passed the recorded digital checks, but physical fit, sealing,
temperature and strength tests are still pending.
